# SKEMA UNINDRA

Website Resmi Sistem Kreativitas Mahasiswa Universitas Indraprasta PGRI.

## Struktur File
- `index.html`: Beranda utama
- `member.html`: Area khusus member
- `admin.html`: Panel kontrol admin
- `style.css`: Lembar gaya tampilan
- `script.js`, `member.js`, `admin.js`: Berkas logika JavaScript
- `config.js`: Konfigurasi sistem
- `db.js`: Pengelola penyimpanan lokal
